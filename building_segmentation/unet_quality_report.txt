6. CADASTRAL FOOTPRINT EXTRACTION & REFINEMENT
--------------------------------------------------------------------------------
Script             : refine_footprints.py
Post-processing    : 
  - Probabilistic Thresholding (tau = 0.50)
  - Conservative Morphology (3x3 structuring elements to prevent merging)
  - Connected Component Segmentation (cv2.RETR_EXTERNAL)
  - Area Filtering (min_area >= 30 sq. pixels)
  - Douglas-Peucker Polygon Simplification (epsilon = 0.005 * perimeter)
Output Format      : GeoJSON (unet_building_footprints.geojson)
Output Coordinate  : Pixel coordinate space
Spatial Note       : Input imagery lacks georeferencing metadata / CRS header.
Total Footprints   : 284 discrete cadastral polygons extracted across 9 test tiles.

7. ERROR ANALYSIS & EDGE CASES
--------------------------------------------------------------------------------
1. High-Reflectance Surfaces:
   - Concrete slabs, paved driveways, and metal warehouse roofs occasionally
     trigger false positives due to spectral similarity with building rooftops.
2. Narrow Alleys:
   - Closely packed residential zones separated by < 3 pixels can fuse if
     morphological operations are too aggressive. The 3x3 conservative kernel
     successfully minimized this merging.
3. Oblique Shadows:
   - Dark cast shadows occasionally truncate building roof boundaries on North/East
     facets. U-Net++'s dense nested skip connections reduced this effect compared
     to YOLOv11-Seg.

8. RECOMMENDATION FOR INTEGRATED PIPELINE
--------------------------------------------------------------------------------
1. Tier 1 (Detection): Use YOLOv11-Seg to generate discrete bounding proposals
   and identify candidate building centroids.
2. Tier 2 (Boundary Delineation): Feed proposals / imagery into U-Net++ for dense,
   pixel-accurate contour segmentation.
3. Tier 3 (Cadastral Vectorization): Run Douglas-Peucker simplification to output
   orthogonalized polygon boundaries ready for GIS parcel mapping.
